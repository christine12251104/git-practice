## インストール

以下の手順で、ふるログをローカル環境にインストールできます。

### 前提条件

> [!NOTE]
> Node.jsがインストールされている必要があります。

### 1. リポジトリをクローン

```bash
git clone https://github.com/your-name/furulog.git
cd furulog
```

### 2. 必要なパッケージをインストール

> [!WARNING]
> パッケージのインストール前に、Node.jsが正しくインストールされていることを確認してください。

```bash
npm install
```
```bash
npm run dev
```

> [!TIP]
> npm run devを実行すると、開発用サーバーが起動します。
> 表示されたURLをブラウザで開くと、アプリを確認できます。
